# P3 — Excelência operacional

**Prioridade:** baixa/contínua (após P2 ou em paralelo leve)  
**Esta fase NÃO está implementada** — apenas planejada

## Objetivo

Elevar o produto a **maturidade SaaS enterprise**: telemetria unificada, deploy sem downtime, qualidade de código mensurável e contratos de API explícitos.

## Impacto

| Área | Ganho |
|------|--------|
| Observabilidade | p95/p99 por tenant; root cause mais rápido |
| Deploy | Canary/blue-green; menos risco em release |
| Qualidade | Dívida de lint explícita e decrescente |
| Integrações | OpenAPI/contratos para rotas de domínio |

## Risco

| Item | Risco | Mitigação |
|------|-------|-----------|
| OTel | Overhead / custo | Sample rate; staging first |
| Blue-green | Complexidade Nginx/PM2 | Começar canary simples |
| Lint massivo | Noise / churn | Quotas por PR; não big-bang |
| OpenAPI | Drift vs código | Gerar/validar no CI |

## Itens (ordem de execução)

### P3.1 — OpenTelemetry + dashboards por tenant
### P3.2 — Blue-green / canary da API
### P3.3 — Reduzir `max-warnings` ESLint gradualmente
### P3.4 — OpenAPI gerado/validado para rotas de domínio

## Arquivos envolvidos

| Área | Paths |
|------|--------|
| Telemetria | `backend/src/logger/**`, `docs/ENGINEERING_TELEMETRY.md`, instrumentação Express |
| Deploy | `deploy/nginx/**`, `ecosystem.config.cjs`, `deploy/docker-compose.api.example.yml` |
| Lint | `package.json` scripts lint, ESLint configs |
| Contratos | `scripts/validate-contracts.mjs`, novos specs OpenAPI, CI |

## Dependências

- Preferível **P2.1** (worker) e **P1.5** (release versionado)
- Stack de métricas (Grafana Cloud, Prometheus, etc.) escolhida

## Critério de aceite

- [ ] Traces/metrics básicos de request + REP + jobs por `company_id`
- [ ] Deploy API com canary ou blue-green documentado e testado
- [ ] `max-warnings` reduzido em degraus com CI verde
- [ ] Contratos OpenAPI das rotas domínio validados no CI

## Rollback

- Desligar export OTel; manter logs Pino
- Voltar deploy single-instance PM2
- Congelar quota de warnings
- Desligar validação OpenAPI no CI se bloquear release crítico
